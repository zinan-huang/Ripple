## 1. Paper definitions and the faithful Lean definitions

### 1.1 Real-time computability, [RTCRN2]

CRN computer, p. 4 (end of §2):

> For a CRN N = (S, R) and a species X ∈ S, we say that (N, X) is a *computer* for a real number
> α if the following three properties hold:
> 1. **Integral Rate Constants.** For each reaction ρ = (r, p, k) ∈ R, the rate constant
>    k ∈ Z>0 is a positive integer.
> 2. **Bounded Concentrations.** There is a constant β such that, if all species concentrations
>    are initialized to 0, then yᵢ(t) ≤ β for each species Yᵢ ∈ S and for all time t ≥ 0.
> 3. **Real-Time Convergence.** If all species in N are initialized to 0 at time 0, then for all
>    t ≥ 1, |x(t) − |α|| ≤ 2^{−t}. (5)

p. 5: "The real numbers for which there is a computer (N, X) are called *real-time CRN
computable*. The set of real-time CRN computable real numbers is denoted by R_RTCRN." The
generalisation R^{τ,γ}_RTCRN replaces (5) by |x(t) − |α|| ≤ e^{−γt} for all t ≥ τ, and
"**Lemma 1.** R_RTCRN = R^{τ,γ}_RTCRN for all τ, γ ∈ (0, ∞)."

GPAC computer, p. 5 (§3):

> For a PIVP y = (y₁, y₂, ..., yₙ) satisfying y(0) = 0, we say that y is an computer for a real
> number α if the following three properties hold:
> 1. All coefficients of y are integers,
> 2. There is a constant β > 0 such that |yᵢ(t)| ≤ β for all 1 ≤ i ≤ n and t ∈ [0, ∞), and
> 3. |y₁(t) − α| ≤ 2^{−t} for all t ∈ [1, ∞).
>
> The real numbers for which there is a computer y are called real-time GPAC computable. [...]
> R_RTGPAC.

Results used below: Lemmas 5-8 (closure under +, ×, 1/α, −; pp. 8-10), Thm 1 (R_RTCRN is a
field, p. 10), Thm 2 (R_RTCRN = R_RTGPAC, p. 10), Thm 3 (nonzero integer initial values, p. 11),
Thm 4 (e, p. 12), Thm 5 (π, p. 12). Lemma 3 (Direct Convergence, p. 6) is the `x' = f − x`
estimate.

### 1.2 Bounded-time computability, [BAC] (the source of `IsCRNComputable`)

[RTCRN2] defines only the real-time class. The modulus notion that `BoundedTime.lean` cites is
[BAC]:

> **Definition 2.1 (PIVP)** (p. 5). A polynomial initial value problem (PIVP) is a system
> y′(t) = p(y(t)), y(0) = y₀ ∈ Q^d, where p : R^d → R^d is a vector of polynomials with rational
> coefficients. [...] A PIVP is bounded if there exists M > 0 such that ∥y(t)∥ ≤ M for all t ≥ 0.
>
> **Definition 2.3 (Bounded-time computability)** (p. 6). Let x(t) be a designated output
> variable of a bounded PIVP. The system computes a real number α if there exists a time modulus
> µ : N → [0, ∞) such that |x(t) − α| < e^{−r} whenever t > µ(r). The time complexity of the
> computation is the asymptotic growth of µ(r).

### 1.3 LPP computability, [LPP]

Balance equation of a deterministic LPP, Def 5 (p. 9):
b(x) = Σ_{(q₁,q₂)∈Q²} x_{q₁}x_{q₂}(−e_{q₁} − e_{q₂} + Σ_{(q₃,q₄)∈Q²} δ_{q₁,q₂,q₃,q₄}(e_{q₃} + e_{q₄})),
δ ∈ {0,1}.

> **Definition 6 (Probabilistic LPP (PLPP) [6]).** (p. 9) A PLPP is an LPP with transition rules
> in the form qᵢ qⱼ → α_{i,j,k,l} q_k q_l and for every (qᵢ, qⱼ) ∈ Q², we have
> • for every (q_k, q_l) ∈ Q², α_{i,j,k,l} ∈ Q and α_{i,j,k,l} > 0, and
> • Σ_{(q_k,q_l)} α_{i,j,k,l} = 1.

with balance equation (5) and ODE dx/dt = b(x) (6).

> **Definition 9.** (p. 11) A real number ν is said to be computable by an LPP (PLPP, LPUP) if
> there exists an LPP (PLPP, LPUP) such that x(t) = (x₁(t), ..., xₙ(t)) ∈ [0, 1]ⁿ and
> lim_{t→∞} Σ_{i∈M} xᵢ(t) = ν, where M ⊆ {1, ..., n} represents the subset of states marked in
> x. Moreover, all the states xᵢ must be initialized to some positive rational rᵢ ∈ Q ∩ [0, 1],
> in the sense that lim_{N→∞} xᵢ^{(N)}(0) = rᵢ [...].

PP-implementability, Cor 3 (p. 8): a function is PP-implementable iff (i) it is
CRN-implementable (x′ᵢ = p − q xᵢ with p, q ∈ P⁺, p. 8 Thm 2; P⁺ = polynomials with positive
rational coefficients, p. 7), (ii) x′ᵢ has no positive xᵢ² term, (iii) x′ is a quadratic form
system, (iv) x′ is conservative. Thm 16 (p. 22): a quadratic system on the simplex can be turned
into a PLPP by Construction 1 iff it is PP-implementable. Thm 17 (p. 23, [BFK] Lemma 4): a PLPP
with rational probabilities computing ν gives a deterministic LPP computing ν. Main Theorem
(pp. 5, 23): LPPs compute the same numbers in [0, 1] as GPACs and CRNs. Lemma 10 (p. 11):
LPUP-computable iff rational. Lemma 11 (p. 13): products. Cor 18 (p. 23): algebraic numbers.
Cor 19 (p. 24): π/4, e⁻¹, γ, Dottie, Catalan.

Two reading notes. (1) Def 6 literally asks α_{i,j,k,l} > 0 for every (k, l); Construction 1
and Thm 16 (pp. 21-22) produce zero entries and idle rules, so the intended condition is ≥ 0,
which is what `PLPPTransitions.nonneg` encodes. (2) The Lean sources (`LPP/Defs.lean`,
`LPP/Stages.lean`) record that the Stage 3 field of Thm 15 (p. 19) is conservative
only on the self-product manifold, not formally; `LPP/SymmetricSquaring.lean` replaces it by a
formally conservative upper-triangular lift (`CubicTransfers.symmetricLift`,
`symmetricSynPP`). The Main Theorem is not affected; its Stage 3 proof is.

### 1.4 Faithful Lean definitions

```lean
/-- [BAC] Def 2.1 + 2.3: computed by a bounded ℚ-PIVP with some time modulus. -/
def IsCRNComputable (α : ℝ) : Prop :=
  ∃ d : ℕ, Nonempty (CertifiedBoundedTimeComputable d α)

/-- [RTCRN2] §3, R_RTGPAC, in the [BAC] modulus form (linear modulus). -/
def IsRealTimeComputable (α : ℝ) : Prop :=
  ∃ d : ℕ, ∃ btc : CertifiedBoundedTimeComputable d α,
    ∃ C : ℝ, 0 < C ∧ ∀ r : ℕ, btc.modulus r ≤ C * (↑r + 1)

/-- [BAC] §5 floor n. -/
def IsPolyTimeComputable (α : ℝ) (n : ℕ) : Prop :=
  ∃ d : ℕ, ∃ btc : CertifiedBoundedTimeComputable d α,
    ∃ C : ℝ, 0 < C ∧ ∀ r : ℕ, btc.modulus r ≤ C * (↑r + 1) ^ n

/-- [LPP] Def 6 + Def 9, PLPP clause. -/
structure PLPPComputation (ν : ℝ) where
  n : ℕ
  tr : PLPPTransitions n
  marked : Finset (Fin n)
  comp : PLPPContinuumComputation tr marked ν

def IsPLPPComputable (ν : ℝ) : Prop := Nonempty (PLPPComputation ν)

/-- [LPP] Def 5 + Def 9, LPP clause (deterministic). -/
structure LPPComputation (ν : ℝ) where
  n : ℕ
  tr : LPPTransitions n
  marked : Finset (Fin n)
  comp : PLPPContinuumComputation tr.toPLPP marked ν

def IsLPPComputable (ν : ℝ) : Prop := Nonempty (LPPComputation ν)
```

Paper-literal companion statements:

- `isRealTimeComputable_iff_rtgpac` (`Ripple/Core/RealTimeGPAC.lean`):
  `IsRealTimeComputable α ↔ IsRTGPACComputable α`, where `IsRTGPACComputable α` says: there is a
  `PolyPIVP` with all initial values 0, all coefficients integers, a solution with
  |yᵢ(t)| ≤ β on [0,∞) and |y_out(t) − α| ≤ 2^{−t} for t ≥ 1 ([RTCRN2] p. 5). The proof shifts
  `p(z + y₀)` in `MvPolynomial` (ℚ is kept), scales time by an integer L (which clears
  denominators and gives the rate, [RTCRN2] Lemma 1 for GPACs), and converts between the modulus
  and the rate.
- `IsPLPPComputable` is the PLPP clause of Def 9 and `IsLPPComputable` the deterministic clause
  (δ ∈ {0,1}, Def 5). They define the same class by [LPP] Thm 17 = [BFK] Lemma 4:
  `isLPPComputable_iff_isPLPPComputable` (`Ripple/LPP/Determinization.lean`;
  `IsPLPPComputable.isLPPComputable` is the Thm 17 direction; proof in `S1-THM17.md`).
- The name `IsCRNComputable` covers the GPAC class. [RTCRN2] Thm 2 gives R_RTCRN = R_RTGPAC for
  real time; for α ∈ [0, 1] a ℚ-polynomial zero-init system is turned into a CBTC
  with a `PolyCRNDecomposition` by `btc_to_cbtc_pcd_of_unit_interval` ([BAC] §7).

### 1.5 Do the existing certified notions match?

| requirement | paper | `CertifiedBoundedTimeComputable` (`Core/BoundedTime.lean`) |
|---|---|---|
| coefficients | ℚ ([BAC] 2.1); integers ([RTCRN2] p. 5) | `PolyPIVP.field : Fin d → MvPolynomial (Fin d) ℚ`: matches [BAC]; integers via time scaling (not formalised) |
| initial value | y₀ ∈ ℚ^d ([BAC]); 0 ([RTCRN2]) | `PolyPIVP.init : Fin d → ℚ`: matches [BAC]; zero via shift (not formalised for `PolyPIVP`) |
| solution | the unique maximal solution | `sol : PIVP.Solution P.toPIVP`, `HasDerivAt` for t ≥ 0; polynomial fields are locally Lipschitz, so on [0,∞) it is the solution |
| boundedness | ∥y(t)∥ ≤ M for t ≥ 0 | `bounded`: same |
| convergence | \|x(t) − α\| < e^{−r} for t > µ(r) | `convergence`: same; µ : ℕ → ℝ instead of [0,∞) (harmless: max with 0) |
| real-time | 2^{−t} for t ≥ 1 (≡ e^{−γt}, t ≥ τ, Lemma 1) | `modulus r ≤ C(r+1)`: equivalent class (convert µ ↔ (τ, γ)) |
| extra | none | `trajectory_continuous : Continuous sol.trajectory` (global, including t < 0): derivable after re-choosing the trajectory for t < 0; a redundant field, harmless for fidelity |

`IsCRNComputable` = [BAC] Def 2.1 + 2.3; `IsRealTimeComputable` = R_RTGPAC (class
level, `isRealTimeComputable_iff_rtgpac`). Both match. For LPP, `PLPPTransitions` + `PLPPContinuumComputation` match Def 6
(with ≥ 0) and Def 9: rational initial values, simplex and nonnegativity (hence [0,1]ⁿ), the
balance ODE (`balanceField`, Eq. (5), formally conservative), the marked-sum limit.
`SynPPBalance` (`LPP/Syntactic.lean`) satisfies Cor 3 (i)-(iv): ℚ≥0 coefficients,
quadratic, `sum_coeff = 2` (formal conservation), and no positive self-square follows from
the last two. The semantic `IsPPImplementable` (`LPP/Defs.lean`) and `IsCRNImplementable` (`LPP/Defs.lean`,
`IsPositivePoly` is nonnegativity of values, not of coefficients) are weaker than the paper's
syntactic conditions and are not used to define the computability predicates.
